# 잔광의 계곡 — 최종 검증과 시각 검토

검토일: 2026-09-29 (한국 시간). 최종 기계 기록은 `SUMMARY.json`, 최종 실행 증거는 `release/`입니다. 결과는 기능 통과와 시각적 평가를 나누어 기록했습니다.

## 실행 및 기능 판정

`release/build-check.json`에 최종 게임 소스의 SHA-256과 실행 종료 코드가 있습니다. 타입 검사 및 프로덕션 빌드가 통과했고, 지형·공격 타이밍·회피 무적·진행 조건·재시작·겹침 관련 회귀 검사 8개가 모두 통과했습니다.

프로덕션 URL에서 시작 버튼, WASD, 마우스 조준·좌클릭, Space, E만으로 안내 NPC 대화, 남쪽 적 4체, 남쪽 등불, 다리, 북쪽 적 7체, 북쪽 등불, 계단, 보스, 제단 상호작용, 승리까지 진행했습니다. 승리 상태에서 새 여정을 시작한 다음 일반 적에게 공격받아 사망했고, 사망 화면에서도 다시 시작했습니다. 최종 실행의 처리되지 않은 런타임 오류와 실패한 리소스 요청은 0건입니다.

현재 상태와 투영 좌표는 읽기 전용 관측 API로 읽었습니다. 개발용 장면 이동, 체력 변경, 시뮬레이션 시간 가속, 강제 승리는 사용하지 않았습니다. 타이틀부터 승리까지 게임 내 시간은 154.9초입니다. 목표를 아는 자동 입력이므로 초회 사람 플레이 시간과 같지 않으며, **요청된 초회 5~8분 분량을 검증한 것은 아닙니다.**

## 관측 후 수정한 문제

초기 나무 수관의 층상 실루엣을 불규칙한 잎 클러스터로 수정하고 물안개를 추가했습니다. 주인공 공격·사망 프레임의 경계 잘림을 발견해 논리적 그림 좌표를 유지하면서 실제 프레임을 72×72로 늘렸습니다. 최종 경계 QC는 잘림 0건입니다.

검의 실제 타격 판정과 타격 포즈의 시점을 맞추고, 주인공이 수호자의 같은 자리에 머무는 겹침을 막았습니다. 회피 무적 표시가 피격과 같은 붉은색이던 문제는 청록색으로 분리했습니다. 제단 등불은 받침에 맞게 낮추고 양옆 등불에 실제 지지대를 추가했으며 바닥 충돌도 맞췄습니다.

초기 자동 플레이는 보스 HP 173에서 사망했습니다. 당시 자료는 `playthrough/`에 보존했습니다. 보스의 부채꼴 예고를 보고 너무 일찍 회피하던 자동 입력은 예고 중 측면 이동과 발사·파동 시점 회피로 바꾸었습니다. 최종 정상 입력 완주와 사망·재시작 기록을 수정 전 실패 기록과 혼동하지 않습니다.

## 최종 남은 항목

기능을 막는 오류는 최종 검증 경로에서 발견되지 않았습니다. 다만 초회 5~8분 분량은 미검증이며 자동 입력 완주가 더 짧았습니다. 신전 바닥과 환경 소품의 반복감, 수호자의 세부 피격·사망 연기에는 추가 미술 작업 여지가 있습니다.

Web Audio의 시작·이벤트 연결과 음소거 상태 전환은 검사했지만 실제 사람이 소리를 듣고 음색·믹스·타격감을 평가하지는 않았습니다. 저사양·다른 브라우저·비정수 DPR·장시간 플레이의 동작도 미검증입니다. 따라서 기능 통과와 본 검토를 근거로 모든 품질 목표가 충족되었다고 선언하지 않습니다.
